Dio HTML-DEVELOPER
 
📘 Formação HTML Developer

Repositório dedicado ao aprendizado de HTML, com conteúdos organizados em módulos progressivos, abordando desde os fundamentos até elementos mais avançados da linguagem.

📚 Sobre o projeto

Este projeto reúne exercícios, exemplos práticos e desafios, com o objetivo de desenvolver uma base sólida em HTML.

Os conteúdos estão organizados em pastas numeradas, facilitando o aprendizado passo a passo.
